## Lab Plot Studio 0.1.1

TEM scale bars and size distributions, stacked XRD patterns with phase identification, and UV-Vis spectra — one window.

### Downloads

| System | File |
|---|---|
| Windows 10 / 11 (64-bit) | `LabPlotStudio-0.1.1-Windows-x64.exe` (single file) or `…-Windows-x64.zip` (folder, starts faster) |
| macOS 11+ on Apple silicon (M1–M4) | `LabPlotStudio-0.1.1-macOS-arm64.dmg` |
| macOS 11+ on Intel | `LabPlotStudio-0.1.1-macOS-x86_64.dmg` |

Every package was started once on its build machine and passed an automatic self-test of all three tools.

**macOS:** the app is not notarized by Apple. On first launch, right-click the app → **Open** → **Open**
(or System Settings → Privacy & Security → **Open Anyway**).

**Windows:** SmartScreen may warn about an unknown publisher; choose **More info** → **Run anyway**.

### Highlights

- XRD: one layer list for patterns and reference cards (PDF / CIF / XY / CSV), drag to reorder, palettes, line widths
- XRD phase ID: multi-phase matching with (hkl) assignment, Scherrer crystallite size, nanocrystal-broadened reference cards
- TEM: automatic scale-bar reading and recalibration, draggable scale bar, zoomed inset, diameter histogram with Gaussian fit and overlay
- UV-Vis: three normalization modes, figure and data export
- English / Chinese interface, light / dark theme, collapsible sidebar
- Windows users of XRD Plotter receive this version through XRD Plotter's own updater; macOS users of XRD Plotter download the DMG above once
- Signed automatic updates: the app checks for new versions at startup (Settings -> Updates) and asks before installing
